Step 03

Connect GitHub

To generate a link that opens on any phone or PC, NEXA is published as a public GitHub Gist using your own token — nothing is sent to any server but GitHub's.

GitHub has no scope literally called "publisher." Use a token scoped only to gist (fine-grained tokens: enable just "Gists — Read and write"). That's the minimum permission needed to create the public page and nothing else.
